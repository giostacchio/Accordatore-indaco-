INDACO TUNER 2.0 - CHITARRA, BASSO E UKULELE

La versione 2.0 aggiunge basso a 4 e 5 corde, ukulele, accordature alternative,
calibrazione A4, tono di riferimento, blocco della corda e una guida pubblica.

Per aggiornare il repository GitHub "Accordatore-indaco-":
1. carica nella root tutti i file della build, senza la cartella .openai;
2. conferma la sostituzione dei file esistenti;
3. esegui il commit;
4. attendi la pubblicazione di GitHub Pages;
5. dal telefono rimuovi l’eventuale vecchia installazione e installa di nuovo.

Il sito deve essere servito in HTTPS per usare il microfono.
